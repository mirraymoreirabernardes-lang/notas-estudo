Diferenças entre Flexbox e Grid

 1. Flexbox
Flexbox organiza elementos em uma dimensão (linha ou coluna), sendo ideal para listas e layouts simples.

 Quando usar:
- Menus
- Listas horizontais ou verticais
- Conteúdos que se adaptam em uma única direção

No projeto:
Usado na página de Filmes.


 2. Grid
O Grid organiza elementos em duas dimensões (linhas e colunas).

Quando usar:
- Galerias
- Páginas com estrutura fixa
- Layouts complexos

 No projeto:
Usado na página de Livros.
